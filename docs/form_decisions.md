# Google Forms 決定清單

本文件是給 Codex / Claude / Gemini 等 agent 接續處理表單時使用的固定決策，避免重複詢問。

## 1. 表單數量

使用兩份表單。

### Form A：投票表單

- 目的：匿名票選與作品評分。
- 原則：完全匿名。
- 記錄內容：作品代號、評分、開放建議。
- 不記錄：Email、姓名、班級、座號、學號。

### Form B：抽獎登記表單

- 目的：抽獎聯絡與領獎確認。
- 可記錄：Email、班級座號或主辦單位需要的聯絡資訊。
- 必須與投票表單脫鉤，不用來回推投票內容。

原因：投票需要保護匿名性；抽獎需要能聯絡中獎者。兩者混在同一份表單會破壞匿名投票。

## 2. Form A 投票表單設定

- 需登入 Google 帳號，優先使用學校 Google Workspace 帳號。
- 每人限填一次。
- 不收集回覆者 Email，避免投票不匿名。
- 表單題目至少包含：
  - 作品代號：G01 至 G20 下拉選單。
  - 1 至 5 分評分。
  - 開放建議欄。

## 3. 一人可投幾件作品

此項尚未定案，需要 KIRIN 最終決定。

可選方案：

1. 每人只能投 1 件最愛。
2. 每人可對 20 件作品各評一次 1 至 5 分。
3. 每人選 3 件最愛。

目前網站與 CSV 統計較適合方案 1 或方案 2。若採方案 2，Google Forms 的「每人限填一次」會與「每件都評一次」衝突，需改成每位觀眾一次填完多件評分，或改用 Apps Script / 後端紀錄。

## 4. 結果呈現方式

- Google Forms 回應綁定 Google Sheet。
- Google Sheet 發布為 CSV。
- 網頁用 `fetch()` 讀 CSV。
- 網站目前使用原生統計卡與 SVG 雷達圖；若需要長條圖，可另接 Chart.js。
- 投票期間只顯示總投票人次，不公開各作品票數。
- 投票截止後才公開排行。

## 5. 防西瓜效應開關

網站使用：

```js
results: {
  publicRankingsOpen: false
}
```

規則：

- `false`：投票期間，只顯示目前總票數。
- `true`：投票截止後，公開各作品排行、雷達圖與分類統計。

此欄位等同於 brief 中提到的 `RESULTS_PUBLIC` 旗標。
