# Google Forms 決定清單

本文件是給 Codex / Claude / Gemini 等 agent 接續處理表單時使用的固定決策，避免重複詢問。

## 1. 表單數量

使用兩份表單。

### Form A：投票表單

- 目的：匿名票選與作品評分。
- 原則：完全匿名。
- 記錄內容：作品代號、評分、開放建議。
- 不記錄：Email、姓名、班級、座號、學號。

### Form B：抽獎登記表單

- 目的：抽獎聯絡與領獎確認。
- 可記錄：Email、班級座號或主辦單位需要的聯絡資訊。
- 必須與投票表單脫鉤，不用來回推投票內容。

原因：投票需要保護匿名性；抽獎需要能聯絡中獎者。兩者混在同一份表單會破壞匿名投票。

## 2. Form A 投票表單設定

- 需登入 Google 帳號，優先使用學校 Google Workspace 帳號。
- 每人限填一次。
- 不收集回覆者 Email，避免投票不匿名。
- 表單題目至少包含：
- 作品代號：依目前公開作品清單提供下拉選單，需和 `works.js` 同步。
  - 1 至 5 分評分。
  - 開放建議欄。

## 3. 一人可投幾件作品

目前定案採用：

- 每位觀眾限投 1 件最想支持的作品。
- 同一份投票表單中，同時對該作品給五項 1 至 5 分評分。
- Google Form 設定「每人限填一次」。

原因：

- 最適合今天社團課快速測試。
- 表單結構簡單，不容易讓學生填錯。
- 統計與人氣票排序最清楚。

若未來改成「每人每天 1 票」或「每人可評全部作品」，Google Forms 內建限制不夠用，需要改 Apps Script Web App / Firebase / Supabase。

## 4. 結果呈現方式

- Google Forms 回應綁定 Google Sheet。
- Google Sheet 發布為 CSV。
- 網頁用 `fetch()` 讀 CSV。
- 網站目前使用原生統計卡與 SVG 雷達圖；若需要長條圖，可另接 Chart.js。
- 投票期間只顯示總投票人次，不公開各作品票數。
- 投票截止後才公開排行。

## 5. 防西瓜效應開關

網站使用：

```js
results: {
  publicRankingsOpen: false
}
```

規則：

- `false`：投票期間，只顯示目前總票數。
- `true`：投票截止後，公開各作品排行、雷達圖與分類統計。

此欄位等同於 brief 中提到的 `RESULTS_PUBLIC` 旗標。
