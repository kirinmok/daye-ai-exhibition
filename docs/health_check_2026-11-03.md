### 壞掉的原因（已解決）
G04、G10 兩款都用 `https://unpkg.com/@babel/standalone/babel.min.js` 這條**沒有版本號**的連結。2026-06-16 Babel 8.0.0 正式發布後，unpkg 自動改給 Babel 8，而 Babel 8 的 JSX 編譯輸出多了 `import` 語法，一般 `<script>` 無法執行，整個畫面不渲染，只剩深色底。成果展期間（6 月中以前）仍是 Babel 7，所以當時一切正常。修法：連結釘為 `@babel/standalone@7`。

## 四、展前檢查清單（交給學校／自己照做）

1. **上線**：已於 2026-11-03 13:11–13:24 推上 `main`（f0b9596、adc64cb、e4156e2、a939015）。之後再改任何檔案：把 `sw.js` 的 `VERSION` 與 `index.html` 的 `?v=` 一起改，訪客重新整理兩次就會拿到新版。
2. **校內網路實測（最重要）**：所有作品都靠外部 CDN（unpkg、cdnjs、esm.sh、cdn.tailwindcss.com、gstatic、fonts.googleapis）。開展前一天，用**展場要用的那台電腦和那台平板**、接**學校的網路**，把 16 件作品各開一次。若校網有內容過濾擋到其中任一網域，整款會白屏。
3. **瀏覽器用 Chrome 或 Edge**：FPS 類需要滑鼠鎖定；K01 手把需要 Web Serial，Safari 不支援。電腦**輸入法預設英文**（遊戲內已加保護，英文仍最保險）。
4. **電腦區 vs 平板區**：9 款建議電腦，7 款平板可玩。iPad 用 `#browse/tablet` 入口（只列 7 款）。戶外熱點場景請照 `ipad_outdoor_checklist` 預熱。
5. **音量**：多款有音效，先確認展場喇叭／靜音政策。
6. **投票已結束**：網站已全站標示；若未來要重新開放投票，把 `site-config.js` 的 `eventStatus.closed` 改 `false`、`voting.enabled` 改 `true`。
7. **排行榜**：5 款有 Firebase 排行榜，但目前用的是佔位設定，分數不會真的上傳，不影響遊玩。
8. **雲端原始檔同步**：雲端那份 801-01、micro-dead-zone 也要改同樣的一行，否則下次從雲端重新上傳會把 bug 帶回來。

## 五、中長期建議（不急，展後再做）

- 所有 CDN 連結都寫死完整版本（`react@18.3.1`、`three@0.128.0`…），或直接把套件檔放進 repo 的 `vendor/`，就不再受外部升級影響，校網被擋的風險也歸零。
- G04、G10 可以把 JSX 預先編譯成普通 JS，連 Babel 都不用載，開啟快很多。
- 幫 G09 補回兩個音效檔（雲端原始資料夾應該有）。
