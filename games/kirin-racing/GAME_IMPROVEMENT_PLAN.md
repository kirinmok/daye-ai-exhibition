## 1. 介面（UI / HUD）

### 賽中 HUD 簡化
- 螢幕上只留 4 個即時資訊：**速度 / 車體穩定 / 貨物安全 / 剩餘電量**
- 其他訊息（圈數、賽道區段、配置標籤）退到角落
- HUD 字體加大，賽車中能 1 秒讀完

### 操作回饋強化
- **加速**：粒子拖尾 + 引擎聲漸強
- **碰撞**：螢幕震動 + 重低音
- **轉向**：輪胎煙霧 + 擦地聲
- **抓地**：路面材質視覺差異（濕路反光、乾路無）
- **積水阻力**：水花 particle + 馬達低吼

### 改裝即學習短提示
- 工坊每個選項加 1 行物理因果短句，不是教條：
  - 「載重 +10kg → 轉向慢 0.3 秒」
  - 「光頭胎 → 涉水抓地 -40%」
  - 「防水艙 +5kg → 貨損 -80%」
- 結算頁不只給分數，給「**下次可以怎麼改**」一句提示

### 模組樹可視化（v2.1）
- 已裝備 / 可升級 / 未解鎖三狀態
- 升級前後數值對照（如 Lv.2 → Lv.3）
- 解鎖條件：完成特定任務或測試

## 2. 玩法（核心循環）

### 60 秒一局節奏
- 賽道縮成單圈 60-90 秒（已從 3 圈改 2 圈，可再縮）
- 死亡懲罰：3 秒重來不扣分
- 進步可見：每局結束三選一升級（Roguelite 機制）

### 操作手感
- 方向鍵 / 搖桿輸入到車體反應 < 80ms
- 過彎時車體有 lean 微傾斜
- 漂移有蓄力槽，集滿可衝刺
- 翻車有翻滾動畫，3 秒復位

### 失敗後立即重來
- 翻車 / 沒電 / 時限結束 → 直接 R 鍵重開
- 不要進結算頁 + 多層選單
- 結算頁加「**改裝這個再試一次**」一鍵按鈕

## 3. 關卡（任務系統）

### 三關卡逐步難度
| 關卡 | 主題 | 單一目標 | 解鎖配件 |
|---|---|---|---|
| 1. 噴水池起跑 | 直線速度 | 60 秒內到達終點 | 🛞 輪胎類型 |
| 2. 文化路彎道 | 過彎控制 | 全程不撞牆 | 📏 軸距 |
| 3. 秀泰地下道 | 涉水 | 貨物不損 | ⚙️ 防水/驅動 |

### 每場只一個明確目標
- 不要同時要求「快+穩+省電」
- 一個任務一個 KPI
- 失敗時清楚知道「沒達標的是哪個」

### 隱藏路線
- 每關有捷徑（縮短 20% 距離但風險高）
- 玩家發現後成就感大

## 4. 教學（PBL + STEAM）

### 改裝即學習
- 拿掉長篇說明
- 改裝面板用「**因 → 果**」短句
- 結算頁的拆解話術用「**這台車為什麼這樣**」

### 學習軌跡（隱藏）
- localStorage 記錄玩家選擇歷史
- 觀察玩家是否從「全選最快」漸進到「平衡取捨」
- 課堂上老師可以調出來討論

### 課堂導學三題
（給代課老師用，遊戲 demo 後拋給學生）
1. 「為什麼飆速戰士配置在地下道翻了？」
2. 「越野神獸跑得慢但完成率高，這代表什麼？」
3. 「如果是真實救災任務，你會選哪一台？為什麼？」
