## 1. 客群（KIRIN 7/3 拍板）

- **國小**：注意力天花板約 **30 秒**，愛動手、愛看畫面爆炸
- **國中**：注意力天花板約 **90 秒**，會問「為什麼」，情緒帶得動
- 家長 / 老師是**旁觀者**（不玩、但決定小孩要不要來）

**設計優先級**：先滿足國小 30 秒門檻 → 再讓國中願意多玩 90 秒 → 最後讓家長/老師覺得有教育價值。

## 2. 當前遊戲的診斷

### 2-1 P0 級（不改就完蛋）

#### P0-1 期待錯位：學生以為要「跑得快」，你要他「觀察證據」

- 現況：包裝是「賽車」，核心是「工程實驗」
- 國小看到方向盤 = 我要飆速 → 撞爛就下攤位
- 國中看到方向盤 = 我要贏 → 沒贏就覺得爛

**建議改法**：
- 主標題不用「賽車」，改「**水城救援・工程車 3D**」
- 副標「不是最快贏，是最會改的贏」
- 用「救援分數」取代「名次」當首要 HUD

#### P0-2 Splash 太長

- 現況：18 秒（早上第 66 波已砍過），但國小看到第 3 秒就想按跳過
- 詩性文案（阿嬤的店、童年路口）對國小 = 冗長；對國中 = 說教
- 「▶ 我要試試看」按鈕藏在下面，很多小孩看不到

**建議改法（P0-2a）**：
- Splash **只留 3 幀，每幀 2 秒 = 共 6 秒**
- 幀 1：颱風畫面 +「淹水了」（動畫）
- 幀 2：改車動畫 +「你能設計工程車嗎？」
- 幀 3：救援畫面 +「▶ 開始救援」（超大按鈕）
- 詩性長文案 → 移到「關於這個作品」按鈕（老師/家長點進去讀）

#### P0-3 HUD 資訊爆炸

- 現況：**14 個指標同時顯示**（電量/健康/口碑/在地/取捨/驗證/KM/H/名次/齒輪/Pico W/歷史排行/救出/寶物/撞擊）
- 國小 30 秒盯不到任何一個
- 國中會看，但看到「口碑 0 / 在地 0 / 取捨 0」不知道要幹嘛

**建議改法（P0-3a）**：新手模式只留 3 個
- 🆘 **救出人數**（主目標）
- 💥 **撞擊次數**（懲罰視覺化）
- 🔋 **電量**（時間壓力）
- 其餘（口碑/在地/取捨/齒輪/名次…）**全部延後解鎖**，第二關才顯示

#### P0-4 沒有 dopamine 鉤子（爽點）

- 現況：撞到 -5 分（懲罰），躲過沒獎勵（沉默）
- 國小記得的不是「我學會底盤」，是「爽過那 3 秒」
- 沒爽點 = 沒回頭 = 沒上癮

**建議改法（P0-4a）**：加即時獎勵回饋
- 連續 3 秒不撞 →「連擊 +1」+ 綠色閃 + 音效
- 5 連擊 → 「HOT!」畫面文字 + 分數 x2
- 撿到救援目標 → 慢動作 0.5 秒 + 音效 + 分數 +10 飄字
- 過關 → 全螢幕彩色紙屑 + 「你救了 N 位！」

### 2-2 P1 級（不改會扣分但不致命）

#### P1-1 Pico W 手把定位不清

- 現況：「Pico W 未連線」HUD 一直顯示 — 展場如果 Pico W 掛了尷尬
- **修法**：未連線時**藏起來**，只在連上時才顯示「🎮 Pico W 已連線」（正向訊息）

#### P1-2 Mission 02 節點太多、太雜

- 現況：13 個節點（秀泰地下道、民生南路天橋…），訊息密度過高
- 國小看到 3 個就累了
- **修法**：Mission 02 拆成 **3 個小關**，每關 4 節點，過關解鎖下一關
- 展前排 P1（8 天內）

#### P1-3 沒有教學提示

- 現況：撞到石頭只寫「-5 分」，沒解釋為什麼
- 國中會想「為什麼扣分？我做錯什麼？」
- **修法**：撞到 → 淡入 tooltip「因為你選了低底盤，撞到石頭會掉零件」

#### P1-4 改裝介面對國小太複雜

- 現況：7 種分類（tire, wheelbase, drive, power, gear, shell, chassis）
- 國小看到 7 個標籤 → 直接放棄
- **修法**：新手第一次只解鎖 **3 個分類**（底盤、輪胎、馬力），玩 2 局後才解鎖其他
