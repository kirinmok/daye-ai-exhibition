## 0. 核心設計原則（三條鐵則）

1. **開局零面板**：第一次進遊戲 30 秒內必須摸到方向鍵。所有選單延後。
2. **一屏一決定**：任何畫面最多一個問題、最多三個選項。
3. **關卡鎖死線性**：沒過的關卡不顯示（不是灰掉，是不存在）。

**流程順序鎖死**：`失敗 → 疑問 → 假設 → 改裝 → 驗證 → 新問題(鉤子)`
「押假設」永遠發生在失敗之後，不是開局選單。

## 1. K-01 便當快遞（完整逐屏規格）

### 屏 1：開場（0–10 秒）
- 無 splash 長片頭。黑屏 1 秒淡入。
- 畫面：一台**方形板車**停在起跑線，直線道路往前延伸。
- 唯一文字（螢幕上方，大字）：「把 3 箱便當送到文化夜市 →」
- 唯一提示（下方小字，3 秒後淡出）：「W 前進 · A/D 方向」
- **沒有** HUD、沒有任務卡、沒有押假設、沒有工坊。

### 屏 2：第一次出車（10–40 秒）
- HUD 只有一個元素：右上角「📦 3」（便當剩餘數）。
- 方形板車物理特性：**直線會左右飄**（每 2 秒隨機側偏力）。
- 側偏累積超過閾值 → 掉 1 箱：
  - 慢動作 0.4 秒，便當盒滾出畫面
  - 「📦 3 → 2」紅色閃一下
  - **不解釋為什麼**（讓疑問自己長出來）
- 中途一個緩彎（方形車轉彎輕鬆過 — 埋下 K-01B 對比伏筆）。

### 屏 3：結算 + 押假設（40–55 秒）
- 到終點。結算畫面只有：
  - 大字：「送達 1 / 3 箱」
  - 一個問題：「**車子直線一直飄，你覺得是為什麼？**」
  - 三個選項（大按鈕直排）：
    1. 「車身太短，容易左右晃」 ← 正解
    2. 「輪子太滑」
    3. 「我技術太爛」
- 選 2 或 3 → 溫柔打臉：「再試一次看看？」再跑一次還是飄 → 回到這屏（選項 2/3 變灰）。
- 選 1 → 進屏 4。

### 屏 4：工坊（55–65 秒）
- 工坊畫面**只有一個決定**：「換車身」
- 兩個選項並排（含小圖 + 一句話）：
  - 方形板車：「轉彎靈活 · 直線會飄」（目前）
  - 長方形板車：「直線穩定 · 轉彎半徑大」
- 選長方形 → 大按鈕「🔧 換好了，再送一次！」

### 屏 5：驗證出車（65–85 秒）
- 長方形車直線穩（側偏力減 80%）。
- 每過一個檢查點：「+1 箱安全 ✓」綠色小字 + 音效。
- 3 箱全到 → 全螢幕彩紙 + 「🎓 工程師認證 Lv.1」
- 連擊系統（已實作）在此關生效。

### 屏 6：鉤子（85–90 秒）
- 結算下方一行字浮出：
  「長車直線超穩！**但夜市裡面的巷子…好像很窄？**」
- 按鈕：「▶ 挑戰夜市窄巷」→ K-01B

### K-01B 夜市窄巷（K-01 的下半場）
- 場景：窄巷 + 連續彎。長方形車**轉彎會卡牆**。
- 同樣流程：失敗（卡牆掉箱）→ 押假設 → 工坊多一個「窄長載貨板」選項 → 驗證。
- 學到的科學：**沒有完美的車，只有適合任務的車**（取捨概念第一次出現）。
- 過關 → 解鎖 K-02 + 預告：「天氣預報：颱風接近中 🌀」

## 2. K-02 → K-04（沿用 Codex 解鎖架構 + 新敘事）

| 關 | 場景/情緒 | 任務 | 新解鎖改裝 | 科學概念 | 結尾鉤子 |
|---|---|---|---|---|---|
| K-02 | 颱風前（天空變暗）| 運沙包/木板加固老屋 | 輪胎、底盤、齒比 | 抓地力、底盤高度、扭力 | 「雨開始下了…」 |
| K-03 | 淹水中（緊急）| 送飲用水/藥品給災民 | 驅動、動力 | AWD、能耗、續航 | 「山區傳來土石流警報」 |
| K-04 | 土石流+坍方（極限）| 全域救援、繞道決策 | 車殼、預設車、預算 | 系統取捨、有限資源 | 「工程師最終認證」 |

- 每關內部都跑同一個 loop：失敗 → 押假設 → 改裝 → 驗證 → 鉤子。
- 每關「押假設」選項數固定 3 個，改裝選項最多 3 個。
- K-02 起 HUD 逐步加回：K-02 加「⚡ 電量」，K-03 加「💥 撞擊」，K-04 才有完整面板。
  （HUD 也是解鎖出來的 — 面板複雜度 = 玩家能力的獎勵）

## 5. 驗收標準（每屏過這關才算完成）

1. 國小生測試：不用任何人教，30 秒內開始開車。
2. 90 秒內經歷「失敗 → 自己說出為什麼 → 改車 → 成功」完整 loop。
3. 玩完 K-01 主動問「還有下一關嗎？」= 成功；問「然後咧？」= 失敗重調。
4. 任何一屏的文字量 ≤ 2 行 + 3 按鈕。
